# JavaQuiz - UT3

Proyecto de práctica desarrollado en Java correspondiente a la Unidad de Trabajo 3 (UT3). Consiste en un cuestionario interactivo por consola donde el usuario responde a preguntas de opción múltiple mediante teclado.

##  Características

* Preguntas de opción múltiple (A, B, C) sobre conceptos de Java.
* Lectura de respuestas del usuario por consola mediante `Scanner`.
* Validación de respuestas y cálculo de puntuación.

##  Tecnologías utilizadas

* **Lenguaje:** Java
* **IDE:** Visual Studio Code
* **Control de versiones:** Git y GitHub

## Cómo ejecutar el proyecto

1. Clona este repositorio en tu equipo:
   ```bash
   git clone https://github.com
   ```
2. Entra en la carpeta del proyecto:
   ```bash
   cd JavaQuiz-UT3
   ```
3. Compila y ejecuta el archivo principal:
   ```bash
   javac src/JavaQuiz.java
   java -cp src JavaQuiz
   ```
